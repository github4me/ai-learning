# 独立文档小实验

这些英文短段落为本课程原创教学材料（2026-09-08），不来自外部抓取或私人资料。8 篇训练文档与 3 篇验证文档按完整文档预先划分；题材有共同点，但原文不同。验证文档不参与梯度更新。

这不是语言能力 benchmark：材料少、文风单一，同一作者造成的偏差仍存在。验证集用于练习独立评估方法；若不断根据它调参，它不再是一次性最终测试集。

`course_data.py` 独立规定 30 字符词表：英文小写 a–z、空格、句点、逗号、换行。它不从验证内容学习词表，没有 UNK、PAD、BOS 或 EOS。文件换行统一为 LF 后编码，其他字符不静默转换。

`week12_generalization.py` 在每个 split 内按文档切 T+1 窗口。stride=T，因此目标位置不重叠；窗口最后不足 T+1 的尾部不参与本实验，报告记录实际有效目标数。不会跨文档拼接，也不会把验证材料加入训练。

运行时生成 `data_report.json`：记录文档名、规范化文本 SHA-256、字符数、窗口数、完整包含检查和忽略空白差异后的 48 字符交集。长片段检查是有限的重复审查，不证明所有近似重复、主题偏差或数据问题都已消失。
